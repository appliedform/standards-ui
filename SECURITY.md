# Security reporting

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting for Standards UI](https://github.com/appliedform/standards-ui/security/advisories/new).

**Enablement has not been verified. Maintainers must verify that private vulnerability
reporting is enabled and the reporting link works before release.** If it is unavailable,
do not place vulnerability details in a public issue. A public request to enable a
private reporting channel may identify the missing channel without disclosing the flaw.

Include the affected package/version or commit, a minimal reproduction, the expected
security boundary and observed impact. Use synthetic data and remove credentials,
personal information and unrelated private material. Do not include live secrets in a
report or demonstrate a flaw against another person's system without authorisation.

Ordinary component bugs, design defects and feature requests can use public issues;
see [CONTRIBUTING.md](CONTRIBUTING.md).
